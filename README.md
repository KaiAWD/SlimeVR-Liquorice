# SlimeVR-Liquorice
A work in progress case and strap design for the SlimeVR stacked smol slime tracker with a case that slides together.

![](https://github.com/KaiAWD/SlimeVR-Liquorice/blob/62f331bcf9c3195a4d9ba9d4474f2a1d4d309a6b/Images/Assembly.gif)
![](https://github.com/KaiAWD/SlimeVR-Liquorice/blob/2f60e6afccbac998eecae2485dbe4d71aa9d8f1e/Images/Trackers%20Overview.png)

The parts are designed to be printed with a 0.2mm layer height, a 0.4mm nozzle and can be printed without supports.

### Parts Used
| Part | Description | Link |
| ---- | ----------- | ---- |
| Elastic Band | EB312-Black-30mm, 5Meters | ![AliExpress Link](https://www.aliexpress.com/item/1005003917576160.html) |
| ProMicro nRF52840 | NRF52840 variant (Without Antenna/IPEX) | ![AliExpress Link](https://aliexpress.com/item/1005007266112508.html) |
| 401230 LiPo Battery | 3.7V 130mAh; Max 4mm High, 12mm Wide, 30mm Long | |

### Versions
There are several versions of the case, both the default case and the case with the tag cutout are available with the offset.

| Default Case (Top Housing.stl) | Case with Tag Cutout (Top Housing Tagslot.stl) |
